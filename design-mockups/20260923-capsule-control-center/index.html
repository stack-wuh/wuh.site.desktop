⑦三区信息架构

任务 → 编辑器 → 插件，频率与情境递减。分区标签沿用现有 PopLabel 语言（11px / muted / 字距 1px）。

⑧模块卡

双列 tile 为基本单位，文档卡独占整行；chrome-raised 底 + 12px 圆角，hover 描边 primary 42%，active 缩放 0.98（iOS 按压感）。

⑨开关语言

布尔型模块（渲染/跟随/专注）用 iOS 式开关，on 态取 --success-color；状态与编辑器命令通道双向同步。

⑩二级展开

排版/快捷键为「整行模块 + 手风琴子面板」（220ms unfold）；大纲/文件/项目沿用现有子面板形态。

⑪插件贡献点

manifest 新增 capsule 声明；数据单向上报（与 tasks 同族安全模型），宿主按白名单模板渲染，插件帧不触 DOM。先行参考：github-issues。

⑫专注模式

开关式进入（⌘⇧F）：问候/散点图淡出至 5% 不卸载，面板描边染 primary；Esc 或再点退出。点上方 DEMO 按钮可在编辑器 frame 预览。

PART 03 · 交互规则

跨特性约束

层级与退出

  • Esc 逐层退出：子面板 → 查找条 → 面板 → 专注模式
  • 面板点外关（胶囊侧统一监听，面板内点击不冒泡）—— 现状保持
  • 查找条为编辑区内联条，不遮正文；关闭后焦点回编辑器

动效

  • 符号浮现/隐藏 150ms；面板二级展开 220ms；渲染↔源码切换 240ms
  • 模块入场 stagger 一次（60/140/220ms），仅首次打开面板
  • prefers-reduced-motion 下全部静态降级（现有 Capsule 先例）

命令通道映射

  • 模块按钮一律 publishEditorCommand，新增 toggleRender / findReplace / toggleFocus / toggleOutlineFollow 命令
  • 开关态由编辑器侧回推事件，胶囊与动作行双挂点单状态源
  • 命令宿主保持壳层 layout 单实例，禁止双消费

持久化

  • wd.editorRenderMode 渲染开关、wd.editorTypography 排版设置
  • 专注模式 / 大纲跟随为会话态，不持久化
  • 排版设置作用于编辑器 surface CSS 变量，预览分栏不受影响
